# SPRINT POKER

タイパ志向のショートデッキ・ホールデム飲みゲーム。1局3分。

## 仕様

- **使用カード**: 8〜A の **28枚のみ** (7ランク × 4スート)
- **役強度**: ショートデッキ準拠 (**フラッシュ > フルハウス**, **スリーカード > ストレート**)
- **ホイール**: A-8-9-10-J (最弱のストレート)
- **判断時間**: 15秒
- **進行**: 各自スマホで同じルームコードに JOIN → ホストが START

## 構成

- **Cloudflare Workers** + **Durable Objects** + **WebSocket**
- ルームコードで部屋を作って各自のスマホから接続

## 役の強さ（強→弱）

ロイヤルフラッシュ → ストレートフラッシュ → フォーカード → **フラッシュ** → フルハウス → **スリーカード** → ストレート → ツーペア → ワンペア → ハイカード

## 飲み杯数

- **勝負した最弱役のプレイヤー**: 勝負した人数 × 1杯
- **フォールドした人**: 1杯
- **勝負した最強役のプレイヤー** (勝者): 0杯
- 全員フォールド: 全員1杯

## 開発

```bash
npm install
npm run dev      # ローカル wrangler dev
npm run deploy   # Cloudflare Workers にデプロイ
```
