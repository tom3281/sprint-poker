RULES

SHORT DECK
使用カードは 8・9・10・J・Q・K・A の28枚。デッキが薄いので強い役が出やすく、1局の決着が速い。役の強さは通常のホールデムと同じ。
進行
各自スマホで同じルームコードに JOIN (最大8人)。ロビーで全員揃ったらホストが START。判断・フォールドはなし。
配り
自分の手札 2枚（自分だけ見える）と、場の共通カード 5枚。場札は ホストがボタンでめくる: FLOP (3枚) → TURN (1枚) → RIVER (1枚) → SHOWDOWN の順。
ショウダウン
ホストが SHOWDOWN ボタンを押すと、7枚（手札2＋場5）から作れる 最強の5枚役 を全員自動で構成。一番弱い人が飲む。
決勝戦
最弱役が2人以上タイなら、その人達だけで 再配り（場も手札もリセット）して再勝負。決まるまで繰り返す。
飲み杯数
負けた人 → 1杯
それ以外 → 0杯
役の強さ（強→弱）
ロイヤルフラッシュ → ストレートフラッシュ → フォーカード → フルハウス → フラッシュ → ストレート → スリーカード → ツーペア → ワンペア → ハイカード
※ 28枚デッキのストレートは 8-9-10-J-Q / 9-10-J-Q-K / 10-J-Q-K-A の3種類のみ。A は high のみ (A-8 は繋がない)。
